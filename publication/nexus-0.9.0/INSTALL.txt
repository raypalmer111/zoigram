Zoigram 0.9.0 — manual installation
Requires a Zoigram server running 0.20.0 or newer with password authentication.
Do not distribute this client before your community server has been updated.

ENGLISH
Close inZOI and extract the ZIP. Copy the entire InzoiSocial_YV6DPJ folder to your
Windows Documents\inZOI\Mods\InGame folder; keep the exact folder name.
For an update, remove ONLY the old lua and ui subfolders inside this mod folder,
then copy the new files with replacement. Keep online and assets: they contain
your saved session, settings and local photos. Enable one copy of Zoigram.

Open Zoigram > Sign in / create account. Confirm the code shown in the game,
then choose your private login and password in the browser. No email or Steam
connection is required. Save the one-time recovery code somewhere private.
Passwords are 15–128 characters; a long phrase is supported. A login uses
3–32 Latin letters, digits or underscores. Other players see your assigned
public ID, not your private login. Only the moderator can change the public ID.
Existing players: keep your saved session and go to Profile > Edit profile >
Sign-in and recovery BEFORE signing out to attach credentials to the same profile.
If your old session expired before setup, contact the owner; creating another
account will not recover your old posts. Recovery requires the saved recovery code.
Without a password and recovery code, automatic recovery is not available.

Internet access is required to exchange posts, avatars, comments, likes,
follows, reports and private messages with the community server.
Use + to publish a Photo Mode image. Profile > Edit profile lets you upload
your own avatar. The heart opens notifications; the envelope opens messages.
No EXE, DLL, installer script, nested ZIP or server files are in this player ZIP.

РУССКИЙ
Закройте inZOI. Распакуйте ZIP и скопируйте папку InzoiSocial_YV6DPJ целиком в
Документы\inZOI\Mods\InGame. Название папки менять нельзя.
При обновлении удалите ТОЛЬКО старые подпапки lua и ui внутри папки мода,
затем скопируйте новые файлы с заменой. Сохраните online и assets:
в них находятся сеанс, настройки и локальные фото. Включите одну копию Zoigram.
В приложении нажмите «Войти / создать аккаунт», сверьте код с игрой и создайте
логин с паролем в браузере. Почта и Steam не нужны. Сохраните резервный код.
Пароль: 15–128 символов; логин: 3–32 латинские буквы, цифры или _.
Другие игроки видят назначенный публичный ID; менять его может только модератор.
Старый аккаунт: до выхода откройте Профиль → Редактировать → Вход и восстановление.
Публикации и ID сохранятся. Если старый сеанс уже истёк, обратитесь к владельцу.
Новая регистрация не восстановит старый профиль. Без пароля и резервного кода
автоматического восстановления нет. Сервер должен быть обновлён до 0.20.0.
Интернет нужен для публикаций и общения. Установщик запускать не нужно.

NEW IN 0.9.0 — PHOTO UPLOADS
Albums still contain up to 5 photos. Choose their order and cover in the editor.
Source photo files can be up to 64 MiB. With canvas/JPEG support in the game's
browser runtime, preparation supports up to 64 million pixels and creates
a JPEG copy with a maximum edge of 2048 pixels. For an original larger than
2048 pixels on either side, the resized copy is used even if its file size grows.
For smaller dimensions, the original is kept if JPEG would be larger.
Your original local photograph is preserved. After preparation, each transmitted
image must fit the 25 MiB limit of server 0.20.0's resumable upload protocol.
If canvas encoding is unavailable, an original can be sent only when it fits
the protocol limit and server validation: PNG/JPEG/WebP, one frame, 64 x 64
pixels minimum and 32 million pixels maximum. Otherwise, take a smaller photo.
Older clients using the legacy upload endpoint still have an 8 MiB limit.
These limits concern publication photos; avatar limits are separate.
MiB means 1,048,576 bytes. No unlimited uploads are offered.

If a connection fails, keep the draft and use Retry. Photos already accepted
by the server are retained for up to 24 hours and skipped on retry. An interrupted
individual photo starts again; the post appears only after the full album arrives.

The owner can now see upload errors, disk/quota/memory status, active uploads,
backup results and separate restore-test results in the private panel. Scheduled
owner announcements appear in supported game clients and can be dismissed locally.
Diagnostics send only a bounded error category, mod version and available image
size/status information, not passwords, tokens or arbitrary local files.

НОВОЕ В 0.9.0 — ЗАГРУЗКА ФОТО
В альбоме до 5 фото; порядок и обложка выбираются в редакторе.
Исходный файл — до 64 МиБ. Если игровой браузер поддерживает canvas/JPEG,
снимок до 64 миллионов пикселей подготавливается как JPEG с длинной стороной
до 2048 пикселей. Если любая сторона исходника больше 2048 пикселей, используется JPEG-копия,
даже если байтов стало больше. При меньших размерах исходник сохраняется,
если JPEG занимает больше места.
Оригинальное локальное фото сохраняется. После подготовки передаваемое
изображение должно быть не больше 25 МиБ для нового протокола сервера 0.20.0.
Без canvas отправляется исходник, только если он укладывается в этот лимит
и требования сервера: PNG/JPEG/WebP, один кадр, от 64 x 64 пикселей
и не более 32 миллионов пикселей. Иначе сделайте снимок меньшего размера.
Старые клиенты со старым способом загрузки сохраняют ограничение 8 МиБ.
Это ограничения публикаций; у аватаров отдельные лимиты. 1 МиБ = 1 048 576 байт.
При обрыве связи сохраните черновик и нажмите «Повторить». Принятые фотографии
хранятся до 24 часов и повторно не передаются; прерванный отдельный снимок
загружается заново. Пост появляется после получения всего альбома.
У владельца в панели доступны ошибки загрузок, место/квота/память, текущие
загрузки, результаты резервных копий и отдельных проверок восстановления.
Объявления владельца с расписанием видны в игре; их можно скрывать локально.
