Zoigram 0.13.1 - manual installation / установка вручную

ENGLISH
1. Close inZOI and extract this ZIP.
2. Open your Windows Documents folder (including OneDrive/redirected Documents, if used), then inZOI\Mods\InGame.
3. Copy the entire InzoiSocial_YV6DPJ folder from the ZIP into InGame. Keep this exact folder name.
4. Start inZOI, enable one copy of Zoigram and open the Zoi phone.

UPDATING: First remove ONLY the old lua and ui subfolders inside
Documents\inZOI\Mods\InGame\InzoiSocial_YV6DPJ, then copy the new folder with replacement.
Keep the online and assets folders: they hold sign-in/settings and local photos.
No installer, PowerShell command, administrator access or server package is needed.
Do not place another ZIP or a second InzoiSocial_YV6DPJ folder inside the mod folder.

Internet access and Steam sign-in are required for the community features.
Steam sign-in opens in your browser. Only confirm on the official Steam website.
Photos, avatars and social activity are exchanged with the Zoigram community server.
Profile > Edit profile > Upload photo: choose PNG/JPG/WebP up to 8 MB, save in the browser and return to the game.
The avatar is cropped to a circle and updates automatically. You can replace or remove it.
Feed / + / Profile are the main tabs; the heart opens notifications and the envelope opens messages.
Reports are available on posts, profiles and comments. Supported languages: EN / RU / FR / KO.

РУССКИЙ
1. Закройте inZOI и распакуйте архив.
2. Откройте вашу папку «Документы» Windows, затем inZOI\Mods\InGame.
3. Скопируйте туда папку InzoiSocial_YV6DPJ целиком, сохранив её название.
4. Запустите игру, включите одну копию Zoigram и откройте телефон Zoi.
При обновлении сначала удалите ТОЛЬКО подпапки lua и ui внутри старой InzoiSocial_YV6DPJ,
затем скопируйте новую папку с заменой файлов. Папки online и assets сохраните:
в них находятся вход, настройки и локальные фотографии. Запускать скрипты не нужно.
Аватар: Профиль > Редактировать > Загрузить фото. Выберите файл в браузере и сохраните.
Для сообщества нужны интернет и вход через Steam. Язык меняется в настройках профиля.

FRANÇAIS
Fermez inZOI et extrayez l'archive. Copiez le dossier InzoiSocial_YV6DPJ dans
Documents\inZOI\Mods\InGame, sans le renommer. Activez une seule copie du mod dans le jeu.
Mise à jour : supprimez uniquement les anciens sous-dossiers lua et ui du mod,
puis copiez la nouvelle version. Conservez online et assets (connexion, réglages et photos).
Aucun script d'installation n'est nécessaire. Internet et connexion Steam requis.
Avatar : Profil > Modifier le profil > Choisir une photo, puis enregistrez dans le navigateur.
