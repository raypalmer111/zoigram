# ID аккаунтов Zoigram

Публичный ID — это `@имя` под именем пользователя. Начиная с Zoigram 1.0 Creators, ID формируется из выбранного имени и меняется при его изменении. Повторный вход, другой персонаж или сохранение не создают новый профиль.

В приложении можно менять имя и описание. Поле ID показывает текущий результат: строчные буквы, цифры и подчёркивания; пробелы заменяются на `_`, декоративные символы удаляются. Поддерживаются Unicode-имена, включая русский, корейский и китайский. При совпадении сервер добавляет числовой суффикс. Длина результата — до 24 символов Unicode. ID нельзя подменить напрямую через пользовательский API.

Владелец может переопределить ID через закрытую веб-панель или серверную команду. Панель: https://vps-24654da6.vps.ovh.net/admin/ — вход по логину и паролю назначенного владельца. Обычный вход в игровой мод и статус Creator не дают прав модератора. Клиентский мод не содержит административных паролей. Инструкция: ADMIN.md.

Из корневой папки проекта:

```powershell
node server/tools/admin.cjs profiles
node server/tools/admin.cjs profiles '@player_'
node server/tools/admin.cjs set-id '@ТЕКУЩИЙ_ID' new_id 'Причина смены'
```

Вместо `@ТЕКУЩИЙ_ID` можно передать внутренний UUID из команды `profiles`. Новый ID: от 1 до 24 букв любого языка, цифр или `_`, без `@`. Он нормализуется так же, как автоматический ID. Занятый или прежний ID другого пользователя назначить нельзя. Причина обязательна. Переопределение действует до следующей смены имени игроком; изменение только описания его сохраняет.

Для сервера в Docker, из папки `server/deploy`:

```sh
docker compose exec api node tools/admin.cjs profiles
docker compose exec api node tools/admin.cjs set-id '@CURRENT_ID' new_id 'Reason'
```

Ручная смена записывает в журнал модерации старый ID, новый ID и причину. Внутренний UUID, вход, фотографии, лайки, комментарии, подписки и действующие сеансы сохраняются. Старые ID остаются закреплены за исходным аккаунтом и работают в упоминаниях и точном поиске. Это не позволяет другому пользователю перехватить прежний ID.

Команда `profiles` показывает до 100 аккаунтов; необязательный поиск проверяет публичный ID или точный UUID. Команды работают с `server/data` по умолчанию; для другого экземпляра сервера задайте переменную `DATA_DIR`. Не передавайте базу данных и доступ к серверу обычным пользователям.
